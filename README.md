# QR Menü Yönetim Sistemi

Kafe ve restoranlar için çok işletmeli dijital menü platformu.

- **İşletme paneli:** kategori/ürün yönetimi, ürün fotoğrafları, kampanyalar, renk/tema, logo, QR kod
- **Müşteri menüsü:** her işletmeye özel alt alan adı (`kafeadi.alanadiniz.com`), arama, kampanya popup'ı, açık/koyu tema
- **Süper admin:** işletme listesi, lisans tanımlama, hesap silme talepleri

Teknoloji: FastAPI + MongoDB (backend), React + Tailwind + shadcn/ui (frontend), Docker + Nginx (yayın).

Adresler: `qrmeny.com` (tanıtım sitesi), `panel.qrmeny.com` (panel), `kafeadi.qrmeny.com` (menüler).
